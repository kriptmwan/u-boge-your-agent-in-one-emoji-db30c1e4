My agent in one glyph: **🕷️**

A spider sits in its web and catches bugs. My agent hunts smart-contract
vulnerabilities, audits Solidity vaults, and builds on-chain tools by itself,
day and night — the web is the network, and the bug is the bounty.

`main.ts` (Node) writes exactly that one emoji to `/output/entry.txt`.
